# Notas do Projeto

Projeto: Sistema de reclamações de condomínio via WhatsApp + painel web.

Tecnologias:
- Node.js
- Express
- PostgreSQL
- Twilio WhatsApp
- Railway

Funcionalidades atuais:
- Registro de reclamação via WhatsApp
- Protocolo automático
- Painel protegido com senha
- Filtros no painel
- Histórico de status
- Página de detalhes
- Exportação CSV
- Impressão de detalhes
- Impressão de histórico
- Gráficos e rankings

Objetivo futuro:
Melhorar o sistema aos poucos sem quebrar a versão atual.
